# Centro de Bienestar Éxito e Innovación

Sitio web oficial del Centro de Bienestar Éxito e Innovación.

## Descripción

Este proyecto corresponde al desarrollo del sitio web corporativo del Centro de Bienestar Éxito e Innovación.

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Cómo ejecutar el proyecto

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Luego abre:

http://localhost:3000
